# Интерактивная система голосования

Веб-приложение для проведения интерактивных голосований в реальном времени с двумя интерфейсами: панель администратора и страница для участников.

## Возможности

- **Голосование в реальном времени** через WebSocket (Socket.IO)
- **4 типа вопросов**: шкала 1–7, открытый текст, матрица оценок
- **Мгновенные результаты**: графики, таблицы, тепловые карты
- **Защита от повторного голосования** через localStorage
- **Адаптивный дизайн** для мобильных устройств
- Поддержка 20+ одновременных участников

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

```bash
cp .env.example .env
# Отредактируйте .env и задайте свой ADMIN_PASSWORD
```

### 3. Запуск

```bash
npm start
```

Сервер запустится на `http://localhost:3000`.

## Интерфейсы

| URL | Описание |
|-----|----------|
| `http://localhost:3000/` | Страница участника (открытая) |
| `http://localhost:3000/admin` | Панель администратора |

## Переменные окружения

| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `ADMIN_PASSWORD` | `admin123` | Пароль для входа в админ-панель |
| `SESSION_SECRET` | `voting-app-secret-key-2024` | Секрет для шифрования сессий |
| `PORT` | `3000` | Порт сервера |

## Workflow администратора

1. Откройте `/admin` и введите пароль
2. Нажмите **«Запустить»** у нужного вопроса
3. Участники видят вопрос и голосуют
4. Счётчик проголосовавших обновляется в реальном времени
5. Нажмите **«Завершить»** — участники видят результаты
6. Нажмите **«Показать участникам»** для повторного показа результатов
7. Запустите следующий вопрос

## Типы вопросов

- **scale_multi** — шкала от 1 до 7 по нескольким пунктам (с поддержкой варианта «Другое»)
- **open_text** — текстовый ответ (до 2000 символов)
- **matrix** — матрица оценок от 0 до 4 (результаты: суммы и средние с тепловой картой)
